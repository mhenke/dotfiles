## Architecture Guardrails
- `PACKAGES` is the linking allowlist. A new top-level directory changes nothing until it is added there **and** `stow -n -v -t ~ <pkg>` dry-runs clean.
- `opencode/` joined `PACKAGES` on 2026-11-05 (`0d74d3e`). The remaining not-linked directories each carry a reason in `DONT-STOW.md`; read it before proposing a package move, because several are excluded by choice rather than by conflict.
- `sddm-themes/` and `ollama/` are system-level and installed by hand with sudo, so they never travel through Stow.
- `applications/.stow-local-ignore` excludes `dev.zed.Zed.desktop` and `kodi.desktop`. Zed **regenerates** that desktop file on every launch with absolute paths from its own install directory, so linking the tracked copy would let Zed rewrite repo content.
- `gh/` is linked, and `gh/.config/gh/config.yml` is intentionally untracked — stowing it links live local state rather than a repo file. `hosts.yml` holds a real `oauth_token` (mode 0600) and is excluded by both `.gitignore` and `gh/.stow-local-ignore`.
- `packages/*` is generated by `scripts/backup-system.sh`. Edit the generator, never the output.
- Runtime coordination state — lock markers, watchdog logs — lives under `$XDG_RUNTIME_DIR` (0700).

## The hypr lock/idle protocol
Three touchpoints must stay in step, because they are one mechanism: `hypridle_{,ac,battery}.conf`, `hyprlock-guarded.sh`, and `session-watchdog.sh`, wired together by the `UserSettings.conf` flags. Change one and check the other two.

The fragile seam is the respawn loop between the guarded wrapper and the watchdog. Prefer backoff and fail toward **locked**.

## Agent-Specific Instructions

### Orchestrator
Ask which delivery path a change takes — the stow symlink, a service reload, or a re-login/sudo step — and state which one.

### Architect
Treat the hyprlock respawn loop (`session-watchdog.sh` ↔ `hyprlock-guarded.sh` ↔ `unlock_cmd`) as the known fragile area. SDDM, Ollama, tilix and Zen are documented-manual by design.

### Developer
- Use `$HOME`, `$(id -u)`, `${XDG_RUNTIME_DIR:-…}`. Hypr's `unlock_cmd` runs under `sh -c`, where `$UID` is a bashism — use `id -u` there.
- Match the comment style of the file you are editing.

### PR Reviewer
- 🟡 Should Fix: hardcoded home paths, a missing `bash -n`, a stow change without a dry run, hand-edited `packages/*`.

### QA Agent
Critical paths: `stow -R -t ~ <pkg>` relinks, `./verify-setup.sh` passes, edited scripts pass `bash -n`, and `git status` shows no secrets.
Always check whether the live `~/.config/…` path resolves to the edited repo file or to a stale copy.

### Secrets audit
Run both scanners and report which ran: `gitleaks dir .` and `gitleaks git .`, then `trufflehog filesystem . --exclude-paths` and `trufflehog git file://.`. Their defaults carry no repo config here.
