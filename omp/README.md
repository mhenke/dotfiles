# OmniRoute Combos

Per-agent-role model fallback chains ("combos") for omp/OMOS. Chains live in OmniRoute server state, not in dotfiles — `omp/.omp/agent/models.yml` only declares the combo ids as provider handles.

**How to update:** [OMNIROUTE-COMBOS.md](OMNIROUTE-COMBOS.md) — dump/update/verify procedure, chain-structure protocol, known gotchas (dead `oc/*` provider, OpenCode Zen free-tier gating outside OpenCode), current combo inventory.
